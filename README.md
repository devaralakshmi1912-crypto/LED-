LED Blinking Using Arduino Uno
Project Description

This project demonstrates how to blink an LED using an Arduino Uno board.

Components Used

- Arduino Uno
- LED
- 220-ohm resistor

Working

The Arduino Uno controls the LED through digital pin 13. The LED turns ON and OFF at regular intervals using a simple Arduino program.
